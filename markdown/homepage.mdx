<h1>Welcome to Blog App</h1>

{/* prettier-ignore */}
<p>This is a <strong>modern blogging platform</strong> built with Next.js, featuring user authentication, blog post management, and a clean, intuitive interface.</p>

<h2>Features</h2>

<ul>
	<li>
		<strong>Create and Manage Blogs</strong> - Write and publish your thoughts
	</li>
	<li>
		<strong>User Profiles</strong> - Personalized user pages
	</li>
	<li>
		<strong>Authentication</strong> - Secure login and registration
	</li>
	<li>
		<strong>Comments</strong> - Engage with blog posts
	</li>
</ul>

<h2>Getting Started</h2>

<p>To start exploring:</p>

<ol>
	<li>
		<a href='/register'>Register</a> for a new account
	</li>
	<li>
		<a href='/login'>Login</a> to access your dashboard
	</li>
	<li>
		<a href='/blogs/new'>Create a new blog post</a>
	</li>
	<li>
		View <a href='/blogs'>all blogs</a> and <a href='/users'>users</a>
	</li>
</ol>
